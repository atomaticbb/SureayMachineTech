## 1. 判断：多数意见成立，但有几项需要纠正

Claude 对尾题同质化、逐行证据缺失、部分优势支撑不足的批评成立。上版虽然声明“不机械套模板”，实际仍以每页 8 个候选为目标，造成检验、样品、首件类问题反复出现。上轮独立审计核对了原问答去向和能力边界，却漏检了这种语义重复；本次将其加入实质审核。

同时，不能把所有技术说明都当成公司服务承诺，也不能仅凭两个页面谈同一材料就判定关键词蚕食。此次修订保留合理判断，纠正过度推断。

## 2. 更新后的工作规则

### 优势与 FAQ 的分工

**Engineering Advantages：** 每页 3 条，依次回答本产品可供的材料/构造、值得采购的加工/工作面特点、具体定制或配套供货。顺序按产品调整，不强制热处理出现在每页第一条。每条必须能落到具体刀片、结构、工艺或交付配置。

**Technical FAQs：** 每页 6–8 个有效问题。选题后先去重，再确定数量；不保留固定商务尾题。若公司资料不足，可以移除一条候选，而不是再找同类题补满。一般技术解释有成熟来源时可以起草，公司自身的交期、免费试样、随货报告等承诺才需要相应业务资料。

例如 Film 的优势可以列出钢/硬质合金供货选项；FAQ 则解释渐进磨耗和崩刃分别怎样影响选材，避免再次罗列整张材料清单。优势可以写上下刀配套供应；FAQ 则说明什么情况下可只换一把、重磨后的保留件为什么需要考虑。共同主题允许存在，重复答案应消除。

### 来源与状态分别标记

来源类型不是自动递增的可信度：

| 标记 | 含义 | 可以支持的范围 |
| --- | --- | --- |
| C | 当前目录；注明产品 ID 与字段 | 已有供货选项、原参数和问答事实；不等同工厂实测报告 |
| L | Sureay 线上历史内容；注明 URL、访问日期和区块 | 原销售主题与既有声明；不自动恢复绝对性能或后续已纠正内容 |
| P | 成熟原厂/刀厂/材料厂原始资料 | 名称、材料原理、设备与一般技术问题；不作为 Sureay 能力证明 |
| U | 本轮未取得对应资料 | 具体未知项留待核，不能作为已确认承诺 |

| 状态 | 含义 |
| --- | --- |
| DRAFT-ready | 在表述已限定范围内，可写供用户审核的英文稿；**不代表已获发布批准** |
| HOLD | 指定主张依赖未取得的材料/服务/效果资料，暂不进入英文营销稿 |
| MERGE / DROP | 编辑处理：合并有用信息或撤掉同质候选。不是说该技术概念错误，也不是删原规格 |

一个优势有 C 支持的材料选项，又有 U 的寿命倍率时，应把材料选题保留为 DRAFT-ready，寿命倍率另列 HOLD。不能用一个状态掩盖两种不同事实。

### 问题排序

P1：直接影响零件识别、替换采购或本产品主要决策；P2：产品专属失效、选材、几何与维护；P3：补充名称/比较/采购细节。根据页面入口意图调整次序，不要求“材料永远第一”。每行写明具体原因。

GSC 2026-10-17—11-13 的现有记录可用于判断页面词语归属，例如 Film、Paper、Carbide 的不同查询；它不是每个 FAQ 的月搜索量，也不是最新 PAA。没有问题级数据时，这里的优先级是有依据的编辑判断。来源见[原 Slitter SEO 审查](../seo-audits/blades-2026-11-16-slitter.md)、[页面/GSC 清单](../seo-audits/blades-2026-11-16-page-inventory.csv)和[搜索访问限制记录](../seo-audits/commercial-seo-slitter-before-2026-11-16.md)。

## 3. 集中能力核对：哪些能用，哪些仍需资料

本轮已读取当前目录、原问答和线上内容；并未取得新的炉次记录、量测报告或公司商务政策。以下是资料核对结果，不是要求每一项补齐才能继续。

| 核对项 | 当前已有依据 | 本轮可起草的内容 | 待确认的具体主张 |
| --- | --- | --- | --- |
| 材料与构造 | 各页 Material、Hardness、Blade options 及原 FAQ | 各产品确有记录的钢、硬质合金、实心/镶刃选择 | 特定牌号的供方与实际状态；Battery 逐牌号硬度；不能以牌号相近推等同 |
| 热处理 | 部分原站与企业介绍提到处理工艺 | 有产品级依据的工艺主题可讨论；没有证据时用已有材料/构造优势 | 每种钢/型号对应的真空、深冷、回火流程；不能全站默认同工艺 |
| 精度与检测 | 现有刀厚、跳动、槽宽、孔配合等规格 | 精磨工作面、明确的零件几何配置；原规格继续保留 | 数值适用尺寸、测量基准、抽检/全检、实际报告样例；不把刀具公差当成品质量保证 |
| 涂层 | 各产品 Optional Coatings | 针对刀材与应用选择已有可选涂层 | 允许组合、ESD 效果、减粘/寿命数字、全部刀材都可用的承诺 |
| 图纸/样件定制与配套 | 各页原 FAQ 已直接说明 | 已有孔型、轮廓、锁紧和上下刀/隔套等具体供应范围 | 未记录的新配件供货、免费逆向工程、全机型免调整安装 |

这份核对将未知限定到具体主张，能够先起草已有供货内容。不能把“没有取得资料”写成“工厂没有能力”，也不能把竞品能力当成 Sureay 的能力。

### 本次材料与线上核查的实际结果

- ASP23 与 ASP2023 的历史更名关系有 Erasteel 官方说明；ASP2023 和 ASP2052 的原厂成分表不同。建议在实际供材确认后规范新旧名称，不能把 2052 合并成 2023。[Erasteel ASP2023](https://www.erasteel.com/products/asp-2023/)、[ASP2052](https://www.erasteel.com/products/asp-2052/)；历史名称原文及版本差异见[材料核对记录](evidence/slitter-advantages-faq-2026-11-17/live-and-material-check.md)。
- CUTSTAR 原厂表明确列 YG8 为 89.0 HRA；Miller 表对相应牌号给出不同数值且表头同时标 HRA/HV。这足以说明不能凭一个总范围替代逐牌号核对，仍不足以判定 Sureay 实际供材错误。[CUTSTAR 原厂牌号表](https://www.cutstar.cn/public/uploads/files/2018/08/Tungsten%20Carbide%20Grade%20Charts.pdf)、[Miller 原厂表](https://www.millercarbide.cn/grade-performance/)。本轮不融合不同厂家数值，不改原规格。
- 已检查全部 13 个当前 Slitter 地址：12 页取得对应的原 Engineering Advantages；`corrugated-slotter-knives` 当前线上返回 404，原优势内容记 NOT FOUND。此项只说明线上对照的覆盖，不宣称本地产品页失效，也不在本轮更改路由。

上述来源访问日期为 2026-11-17，完整原表头、位置和限制已归档。本轮所有 YG 硬度均未取得两个独立来源在相同条件下一致的验证，不能标为行业通用高可信参数。

## 4. 页面之间怎样分工

| 页面 | FAQ 材料/结构题的具体角度 | 需要深入比较时的相邻入口 |
| --- | --- | --- |
