# Sureay 网站上线前验收 · 2026-11-23

**发布判断：暂缓切换生产流量。** 刀片目录、八种语言的页面、旧网址迁移和英文手册已在本地正式构建通过。上线前优先保证三件事：发布的代码与验收版本一致，重建容器后能读写并恢复原有询盘，销售在邮件故障后仍能取得客户的图纸。

验收对象是 11 月 23 日的本地工作目录。当前 Git 提交为 `9999a7c`（11 月 5 日）。本轮只对线上公开页面做了读取。所有测试询价、下载登记和邮件故障模拟均使用隔离数据，没有发送真实邮件。

### 手机慢网性能

对同一正式构建使用 Lighthouse 12.8.2 移动端模拟限速，各页面测三次。以图片能正常加载的 `localhost` 结果为准，排除外部统计请求。项目的首屏最大内容显示时间（LCP）目标为 2.5 秒，布局偏移（CLS）目标为 0.10。

| 页面 | LCP 中位数 | CLS 中位数 | 三次结果的含义 |
|---|---:|---:|---|
| 英文首页 | 7.26 秒 | <0.001 | 三次 LCP 为 5.70–7.46 秒，均超过目标。 |
| 英文纸刀产品详情 | 5.79 秒 | 0.000 | 三次 LCP 为 5.78–5.93 秒，布局稳定。 |
| 英文产品总览 | 5.39 秒 | 0.090 | 三次 LCP 均超过 5 秒，CLS 一次为 0.180、两次约 0.090，布局跳动偶发超过目标。 |

建议先排查首页首图加载完成后的绘制等待。手机已取得约 13 KB 的专用 WebP；首页中位数那次测量中，绘制等待约占 LCP 的 81%。可先分析前端启动时重绘的时间，并推迟首屏用不到的菜单图片和新闻数据。法语首页与英文产品总览在 390px 手机上仍使用与桌面相同的首图文件，可补充合适的手机尺寸。以上均为本地模拟值，线上真实用户表现需在发布后单独观察。[性能结果](../../qa-results/prelaunch-2026-11-23/verified-performance/lighthouse-summary.json) · [浏览器实际选图](../../qa-results/prelaunch-2026-11-23/verified-performance/images-runtime.json)

## 四、切流与发布后复核

- **切流前**：在实际 Linux 容器和同类持久卷完成上表四项验收。用预发布域名或生产同类代理核对首页、静态图片、英文 PDF、旧网址跳转和新网址。检查邮件收件人覆盖配置，避免测试收件地址被带入生产。
- **切流当天**：用指定测试联系人完成一笔带图询价及一次英文手册下载，核对后台记录、销售实际收到的附件和回执。在 GA4 DebugView 验证浏览、询价和下载事件。生产凭据、真实邮箱投递、真实 iPhone Safari / Android 手势体验均须在对应环境验收。
- **切流后 24–48 小时**：向 Search Console 提交新的站点地图，抽查八语新旧网址及语言替代链接，持续观察收录变化。核对实际询盘、附件邮件失败、手册下载和服务器错误；若关键写入或附件交付中断，执行已演练的回退，并保全切流后新增数据。
