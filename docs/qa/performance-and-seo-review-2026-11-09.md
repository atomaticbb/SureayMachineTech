# 性能优化建议与链接、SEO 检查

日期：2026-11-09。检查对象为当前本地生产构建及 Express 服务；性能采用先前 Lighthouse 12.8.2 七个移动端样本、各三次的结果。未修改网站代码。由于网络不稳定，外部站点、搜索引擎索引和线上部署状态本次未验证。

## 性能：建议先验证，再实施

LCP 七页中位数 5.74–8.04 秒；CLS 全部不超过 0.1。Lighthouse 使用模拟限速，实际线上及真实用户表现需要另测。以下节省量是工具估算，不能直接相加或保证达到。

| 顺序 | 建议 | 本地证据 | 验证办法与注意事项 |
|---|---|---|---|
| 1 | 排查预渲染后首屏被 React 重建及等待脚本的问题 | `client/src/main.tsx` 使用 createRoot；预渲染 HTML 已存在；多个样本 LCP 元素是文字，图像样本在 trace 中也有较长渲染等待 | 用 Performance 录屏和首屏时间线确认预渲染内容是否替换、闪烁，构建小范围 hydrateRoot 对照实验；检查水合一致性、多语言与 SEO，避免未经验证直接替换 |
| 2 | 推迟导航下拉菜单图片预取 | `Navbar.tsx` 在所有页面加载时对类别图片执行 `new Image()`；部分图片例如 special-shaped-knife.webp 约 170 KB 出现在多页请求中 | 网络瀑布中对比改为菜单展开或空闲且首屏结束后加载，查看 LCP 和菜单首次打开体验；复用现有图片，非要求重新压缩 |
| 3 | 审核共享 JS 与预热时机 | 各页 `index` 主包约 267 KB 传输；Lighthouse 在样本估计约 85–93 KiB JS 未使用，`ui`、`radix` 共享包存在未使用部分；首页会在空闲或超时后预热产品页 | 做 chunk / Coverage 分析，按需加载菜单和延后预热；比较冷缓存 LCP、TBT 和交互，防止拆包带来更多网络往返。TBT 中位 18–68ms，不能仅凭包大断言主线程是首要瓶颈 |
| 4 | 减少关键样式阻塞 | 本地报告识别全局 CSS 约 29.5 KB 传输，render-blocking insight 估算各页约 0.6–1.05 秒，非保证收益 | 实测 CSS 请求链并评估安全的关键样式拆分；保证预渲染首屏无闪烁、断版，减少低优先级 CSS 的干扰 |
| 5 | 核对单个首屏图的优先级，不做全站重复图片优化 | 产品详情和 Mixer 首屏图已有 eager / high 与可发现性；首页 DOM 有 high 但 Lighthouse 检查结果与 DOM 不一致；产品列表首屏图未标 high | 分别对照初始 HTML、浏览器网络 priority、重建前后 DOM 和 Lighthouse；只针对确有问题的页面做小范围对照，不假定增加 preload 必然改善 |
| 6 | 复查缓存、字体与服务端 | 已有 gzip 压缩和静态资源缓存配置；本地 TTFB 极低，不代表线上；六个自托管 WOFF2 合计约 163 KiB，已使用 swap | 在线上检查实际响应头、不同地区 TTFB 与首屏字体请求；避免重复引入字体或预加载所有字重；无 hash 图片的 immutable 缓存更新策略需与发布方式核对 |

Lighthouse LCP 的模拟值与 trace 的原始时间不是同一尺度；不要把原始子项相加解释为模拟 LCP，也不要把 TBT 当作真实 INP。上述属于候选优化，收益须在同环境 A/B 后决定。

## 已执行的本地链接、导航和 SEO 检查

- 静态构建：596 个 HTML，587 个 sitemap URL 均有对应 HTML；静态扫描未发现内部链接文件缺失或锚点缺失；从英文首页的静态链接图可到达所有英文 sitemap 页面。
- 本地 Express：587 个 sitemap 地址全部返回 HTTP 200 且无最终路径跳转。随机无效页面、无效产品返回 404；已停用的 `/es/news` 返回 410。
- 多语言：595 个构建页面通过语言构建校验；7 路由 × 8 语言 smoke 的 234 项断言通过。4,824 条 hreflang 检查未发现缺目标、语言不符或互指缺失。产品详情桌面和移动菜单的法语切换可以到达对应产品；这是样本验证，不代表每个切换组合均已实点。
- 语言可达性：静态 `<a>` 图中 469 个多语言 sitemap 页面未从英文首页到达。原因是语言菜单的链接在交互后生成；浏览器抽样可切换，且 sitemap/hreflang 有入口。因此不判定为真实孤儿页，但无 JS/静态抓取场景的直接导航是待评估项。
- 两端导航：首页桌面两个菜单键盘打开/关闭及焦点返回通过；桌面和手机抽样均有七个刀片类别、Custom、两类 Mixer、全部产品和联系等核心入口。桌面有额外直接产品链接。Wood Chipper Blades 两端指向 `/categories/wood-chipper-blades`，该 URL 301 到单个产品 `/products/wood-chipper-blades`，属于链接文字与落地层级不完全一致，建议确认正确目标。
- 元信息：596 个 HTML 的 title、description、单 H1、canonical、OG URL 与 JSON-LD 语法由构建检查覆盖；产品详情、分类、行业、Mixer Hub、文章五个样本由产品列表 SPA 切换后，title、description、canonical 和 og:url 与对应初始 HTML 一致。
- 结构化数据：2,121 个 FAQ 问题文本能在对应 HTML 文本中找到；48 篇文章的 Article headline 与 H1 相符。比较只验证文本匹配，不验证答案事实、价格、富结果资格或所有字段。
- 面包屑： ，但页面未展示对应面包屑；文章模板的 BreadcrumbList 包含 Home / News / 文章标题，页面呈现的是返回 Technical Articles 的链接。应统一页面导航与结构化数据的表达。自动扫描中的其余候选仍需逐项复核；`/custom` Product 名称与宣传式 H1 不同本身不构成错误。
