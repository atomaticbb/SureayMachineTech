# 英文刀具产品页升级模板

当前参考页为 Slitter Knives 和 Shredder Blades 的英文分类页及详情页。每次按一个类别更新，先核对已有规格，再用对应类别的本地英文页面验收。

2026-11-23，用户授权将已公开的 Industrial Blades 英文目录同步到西班牙语、法语、俄语、越南语、阿拉伯语、葡萄牙语和土耳其语。下文 11 月 13 日至 16 日的英文单批验收范围是历史记录。本次目录发布按「URL 迁移上线门禁」的八语规则验收，后续新增产品按当批授权范围处理。

## 按品类推进的固定流程

用户指定下一个品类后，主动完成以下流程，不等待用户逐项提醒。Slitter、Shredder 已确认的通用规范直接沿用；其产品参数、适配和供货能力不能移植为其他品类的事实。

1. **接续已有工作。** 先阅读该品类的历史调研报告、最新任务单、本模板及相关待办，记录已确认决定、资料缺口与本次文件基线。向用户说明采用了哪份报告及其日期，不另起一份重复调研。
2. **先审整个品类。** 结合现有全部刀具分类、相邻产品、行业页与成熟整机厂／刀具厂目录，主动分析分类边界、菜单负担、产品重叠与缺口。逐款检查采购用途、正文、实际图片、原尺寸表、安装接口、名称变体和内链；有 GSC 数据时核对查询归属，并注明数据期间。
3. **给出有判断的建议。** 在已有报告中记录每款产品的现状、证据、建议、优先级和待确认项。区分“沿用已确认规范即可实施”“本次新增的业务决定”“缺证据暂不实施”。新增产品须说明独立采购需求及真实供货资料缺口，不能仅因竞品有该产品就建议建页。不能把未查到规格说成原规格错误，也不能把竞品能力写成 Sureay 能力。
4. **按授权范围实施。** 用户要求实施时，已确认的模板、版式和验收要求直接应用，不重复索取确认。用户要求先分析或讨论时，先交付完整建议。尚未授权的新增／删除产品、分类拆合、URL 变更以及与原规格冲突的替换，集中给出具体推荐与影响供用户决定；不阻塞已授权且独立的工作。不生成其他语言版本，不擅自执行仅登记为待办的事项。
5. **按整批验收并回写。** 按本文件的类别验收检查分类页和全部详情页，核对规格证据、图片、Item No.、FAQ、内链及结构化数据。向用户交付本地入口、实际改动、检查结果及剩余问题；将新的通用决定补入本模板，品类特有事实留在该品类报告。

沟通按“品类审查结论 → 需要决定的差异 → 实施与验收结果”组织。用户无需反复描述已确认标准；助手负责主动发现问题并给出推荐，不把逐项找问题的责任交回用户。引用既有结论时核对其是否被后续决定替代，保留已确认标准与尚未实施待办的区别。

## 详情页结构与首屏

- 2026-11-16 用户确认：英文公共页面统一使用「区块标题 → 必要的一段简短描述 → 主体内容」。删除 `OEM Compatibility`、`System Inventory`、`Knowledge Base` 等装饰性副标题／眉题，不将其移到别处成为另一层标签。独立补充说明中的有效信息并入对应描述；纯重复的宣传标签删除。标题和描述应足够说明区块用途并自然承载相关搜索词，不为 SEO 堆词或扩大未经证实的适配承诺。原规格、尺寸、件号、功能提示和必要图注不作为装饰文案删除；现有译文不改。
- 同日补充：品牌名称后的 `®` 保留，不属于应删除的副标题。品牌区描述以销售与采购服务为导向，积极说明替换选项、可定制项目和询价服务；型号／图纸核对自然融入服务过程，避免以限制条件和说明书口吻主导文案。Bottom Grooved Anvil Knives 示例已获用户认可并授权推广；逐产品使用实际供货选项，不复制一段泛化描述。
- 当前 Engineering Advantages 调整先停留在讨论：先梳理可用事实、客户价值及能力证据，再确定选题，尚未授权重写卡片。该区不能用 Match / Check / Identify / Distinguish 等选型教程充当优势；与 FAQ 已覆盖的选型解释分工。待确认的寿命、效率、批次一致性、交付及检验承诺不得擅自成为宣传保证。
- 工程优势审查以用户网站的线上原有内容为首要对照，例如 `/products/rotary-slitter-knives` 的材料、防粘涂层、刃口几何三项。保留「产品／工艺特点 → 客户价值」的销售结构；个别效果数字单独核对，不能据此将整个区块替换成选型教程或删除。先记录线上与本地的差异，再讨论修订；不要求用户从零重建已有产品优势。
- 页面和 `BreadcrumbList` 的层级统一为 `Home › Products › 产品名称`。页面标题、规格和关联产品使用各自真实资料。
- 使用共享 `detailLayout`。桌面左侧主图展示框为 480 × 480 px 正方形，右侧整列以首屏顶部为基准固定下移 32 px。手机端上下排列，主图随可用宽度缩小。非正方原图以 `object-contain` 完整展示在方框内，不为满足展示尺寸裁剪或拉伸原图。
- Hero 暂只展示一张主图，不使用缩略图切换（用户于 2026-11-13 确认）。补充产品图放在对应技术区，后续启用首屏图库需另有用户指示。
- 主图保留产品原比例。需要透底时使用 WebP 透明通道与等比例留白。主图与技术图记录实际固有宽高和已存在的宽度变体，组件用 `srcset` 和 `sizes` 选择资源。优先复用已验证的 WebP，桌面和手机分别核对 `currentSrc`。技术图保持原始长宽比。
- 首屏右侧先展示产品名与 `Sizes`，再列已确认的材料、用途等关键信息。保留询价按钮和产品 PDF 入口。
- 英文 Hero 的简短规格统一优先按 `Sizes → Material → Application` 三项排列（2026-11-13 用户补充）。材料使用当前产品的实际钢号／材料选项，应用保持简短；资料缺少时不造材料或使用段落凑满三项。首屏采用现有数据，不生成译文。
- 首屏之后依次复用 `Technical Specifications`、`Common Standard Dimensions`、行内询价入口、适用品牌与已有技术说明或图纸、相关产品、FAQ、页尾询价表单。只展示有资料支撑的可选区块。
- `Compatible Machine Brands` 与 `Engineering Advantages` 是已确认保留的产品区块，不得因精简页面或切换模板而删除。Shear 五款均须显示并作为验收项；品牌与工程文案按当前产品工位核对，存疑参数单列待核，不能以资料待核为由移除整个区块。恢复区块不等于恢复无凭据的精度、寿命或全型号适配承诺。

## 规格与询价

- `Technical Specifications` 必须回答产品实际提供什么：参数值、具体材料／结构选项、适用配置或明确的定制形式。不能用 `Outer diameter, bore and thickness` 这类只有字段名称的清单充当尺寸，也不能用 Identify / Confirm / Send 等询价指令填充规格区（2026-11-13 用户指出问题后确认修正）。
- 每页技术区只保留一条 `Sizes` 摘要，删除重复介绍外径、孔径、宽厚及上／下刀尺寸的条目，详细组合留在原标准尺寸表；筛网 Sizes 明确表示孔径。材料硬度、公差、刃角、槽距等独立技术参数保留。原有可选涂层必须保留并统一用 `Optional Coatings`；镜面和粗糙度继续作为表面质量，不能误当涂层（2026-11-13 用户补充）。
- 以原规格和后续用户确认逐项对照。外部搜索未找到某参数，不是删除原值的依据；后续明确修订、排除或改变定位的项目不得通过恢复原版重新带回。真实冲突留在内部待确认清单，不用泛化文案掩盖。不要机械回滚寿命、绝对性能或全机型适配承诺。
- 模板升级前，必须对照原始目录逐行清点尺寸表。当前工作区缺少原表，不表示用户同意删除；不能用 `Made to Drawing` 或一条示例尺寸代替原有表格。用户审核产品并授权升级，也不等于批准已有缺行。恢复原值与新增调研规格分开记录，并在测试中保留原行数量、各列数值和稳定件号（2026-11-15 六款尺寸恢复纠正）。
- 检查最终实际显示的数据源：`detailLayout.technicalSpecs`、独立 `dimensionTables` 和原 `specs`／`standardDimensions` 都要对照。文件中仍存在但被覆盖、或仅放在不显示的 caption 中的原参数，不能算页面已保留。旧定制尺寸能力合并到单条 Sizes，并与首屏所示的现有配置范围区分；配套零件参数必须标明所属零件。
- 询价输入集中在已有 RFQ；选择理由、名称解释和测量方法进入已有 FAQ 或工程说明。结构和安装形式可以是有效的非数值规格，不要求每页凑相同行数。尺寸摘要必须与各 Item No. 的配置一致，范围不表示长宽厚任意组合。
- 保留用户已确认的行、尺寸、单位、件号和列调整。标准尺寸表以 `Item No.` 开头，采用 `SR` 加三位分类码和三位流水号。Slitter 使用 `SR001`，Shredder 使用 `SR002`，Shear 使用 `SR003`，Log Saw 使用 `SR005`（Tissue 六组为 SR005101–106）。同一配置跨页复用同一编号，按行排序时编号跟随配置。
- Wood Chipper 使用 `SR006`：动刀原八行 101–108，Biber 补充行 109，定砧九行 201–209。Other & Custom 使用 `SR007`：Strand 五行 101–105，Melt Filter 六行 201–206，Cutter Compactor 六行 301–306，Die-Face 六行 401–406。未出现尺寸表的 Custom 产品不预造编号。
- 2026-11-15 全目录复查：Slitter 追加恢复行使用 SR001801–858；Plastic Granulator 原八行 SR002801–808、ZERMA 六行补充 SR002809–814；Nonwoven Log Saw 原六行 SR005201–206。原有编号保持稳定。详细恢复及明确排除项见 [全目录核对记录](../page-audits/catalog-specifications-restoration-2026-11-15.md)。
- 2026-11-16 用户确认：英文产品页取消独立 `Why Choose Sureay` 栏，统一使用单栏 `Technical FAQs`，每页 6–8 个问题。先归并原企业问答中的产品适配、样件定制、检验和成套采购信息；企业事实不能无记录丢弃，也不为凑题硬塞入技术问答。现有译文保持原数据与版式。
- FAQ 按本页实际 GSC 查询、搜索结果的采购意图与技术重要性排序；6 个核心问题，确有独立信息时增至 7–8 个。回答先解决问题，不能反复只要求提交图纸，也不能机械套用全站相同题目。replacement、OEM 适配、custom 和名称变体的新增详细解释只放 Technical FAQs，不另加首屏段落或扩展其他区块。
- 产品名称解释和真实采购别名优先提炼成已有 `Technical FAQs` 的选题与答案，作为后续 SEO 内容优化检查项。同义名称说明适用的设备和刀位，刀型名称对应具体配置。优先完善已有问题，每个答案帮助买家识别或选型，避免重复问答和堆砌叫法。
- 名称类 FAQ 的选题依据包括客户询盘、整机厂用词和 GSC 查询。记录主名称、采购别名及其适用范围，答案用具体设备和选型条件解释关系。上线后按产品 URL 和相关查询核对展示、点击与落地页。
- 首屏维持简洁，名称解释由 FAQ 承载。材质、尺寸和安装参数进入相应规格区域。FAQ 答案随页面渲染，并在发布时核对预渲染 HTML 与可见内容一致。
- 验证面包屑、分类卡片、相关刀具及页内询价入口。单轴转子刀和定刀的两个详情页保留互相指向的原文链接。

## 英文产品标题与采购名称优化（2026-11-16 已授权实施）

- Title 先写完整产品主词，再按实际采购任务选择 replacement、OEM Replacement 或 custom 等主要属性；不用动词短语 replace blades，不把全部商业词机械追加到每个标题。OEM replacement 表达兼容替换用途，不能冒充原厂产品或承诺所有机型适配。
- Meta description 简洁说明实际材料、应用和具体定制项目；H1 保持直接、简洁的产品名称或必要工位。Paper 优先研究 paper cutter blade、paper guillotine knife 等真实采购名称；不拼接关键词清单。卡片名称、URL、分类、图片、原尺寸和 Item No. 不因本轮 SEO 优化而变化。
- 修改前由独立 agent 逐产品核对 Google 查询、成熟厂商用词及可用 GSC 数据，记录查询日期、具体来源、主词/长尾和相邻页分工。Google 访问受限时明确标注，不能把其他搜索渠道或厂家用词冒称为 Google PAA、搜索量或排名。
- 修改后由未参与该批成稿的独立 agent 审计内容、承诺依据、原资料保留、关键词边界、渲染与结构化数据。修正后再验收，不以测试通过代替内容审查。只改英文，不生成其他语言版本，不预设流量或排名收益。
