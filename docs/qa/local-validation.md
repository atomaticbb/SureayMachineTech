## 启动与验证

在仓库根目录执行 `pnpm dev`，访问终端输出的本地地址。建议按以下顺序检查：

1. 首页和产品页：字体、深蓝/白/灰色、轮播和分页；手机窄屏检查底部入口与正文是否互相遮挡。
2. 桌面导航：用 Tab 到产品或混合机菜单，按 Enter 进入链接，按 Escape 关闭并返回入口。
3. 首页 FAQ：Enter/空格展开与收起；俄语首页、产品页、联系页在窄屏横向滚动情况。
4. 打开 Ni-Hard 长文：检查目录、宽表可用键盘滚动、打印；桌面侧栏 Copy Link 的成功提示，若浏览器拒绝剪贴板权限则检查手动复制地址。
5. 联系页：检查必填项和错误提示。真实提交会产生询盘及邮件，请使用预先约定的测试收件配置；不要把模拟响应当成真实送达。

## 人工视觉改动复看

- 在 `/products` 用桌面窗口滚动列表。筛选栏应在产品网格区域内停留，没有内嵌滚动条。窗口较矮时继续下滚，确认仍可到达 Industry 底部和 PDF 按钮。
- 对照 `/categories/shredder-blades`、`/categories/slitter-knives`、`/products` 和 `/plastic-industry`。检查每行列数、行业标签、尺寸文字和 View details，悬停时边框颜色不变。
